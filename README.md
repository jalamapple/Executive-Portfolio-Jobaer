# S M Jobaer Alam — Executive Cloud & Security Portfolio

Official portfolio website for **S M Jobaer Alam** (`www.jobaeralam.com` | `hello@jobaeralam.com`).

## Project Structure

```
jobaeralam-portfolio-project/
├── index.html                           # Complete self-contained portfolio web app
├── web.config                           # Azure App Service (Windows IIS) MIME & default doc config
├── README.md                            # Repository overview & deployment steps
├── MANUAL_UPGRADE_GUIDE.txt             # Step-by-step manual editing reference
├── FREE_SOFTWARE_DISTRIBUTION_GUIDE.md  # Guide for hosting free software/tools
├── images/
│   └── README.txt                       # Place your 500x500 profile.jpg here
└── downloads/
    └── README.txt                       # Place your 6 free tool .zip packages here
```

## Quick Deployment to Azure App Service via GitHub

1. Extract this ZIP archive into your local GitHub repository folder.
2. Add your headshot photo as `images/profile.jpg`.
3. Upload your software/tool `.zip` packages into `downloads/` (matching the filenames in `downloads/README.txt`).
4. Commit and push to your GitHub branch connected to Azure App Service.
5. Verify live at `https://www.jobaeralam.com` and `https://jobaeralam.com`.
