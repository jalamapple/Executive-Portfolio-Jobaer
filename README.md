# S M Jobaer Alam — Modular Executive Portfolio

Official portfolio website for **S M Jobaer Alam** (`www.jobaeralam.com` | `hello@jobaeralam.com`), separated into clean HTML, CSS, and JavaScript modules.

## Project Structure

```
jobaeralam-portfolio-project/
├── index.html                   # Semantic HTML5 markup (links css/styles.css, js/data.js, js/app.js in <head>)
├── css/
│   └── styles.css               # Complete theme, responsive grids, smart typography, animations & print CSS
├── js/
│   ├── data.js                  # Email config, 7 Free Tools catalog, Case Studies, Prompts & ATS Resume data
│   └── app.js                   # Liquid smooth scroll, scroll-spy, live US clocks, modals, filters & form logic
├── staticwebapp.config.json     # Azure Static Web Apps routing & MIME configuration
├── web.config                   # Azure App Service (Windows IIS) MIME & rewrite configuration
├── README.md                    # Repository overview & deployment steps
├── images/
│   └── README.txt               # Place your 500x500 profile.jpg here
└── downloads/
    └── README.txt               # Place your 7 free tool .zip packages here
```

## Quick Deployment to GitHub & Azure

1. Extract this ZIP archive into your local GitHub repository folder.
2. Add your portrait photo as `images/profile.jpg` (500x500 px).
3. Add your software/tool `.zip` packages into `downloads/` (matching `downloads/README.txt`).
4. Commit and push all files to GitHub to auto-deploy to Azure.
