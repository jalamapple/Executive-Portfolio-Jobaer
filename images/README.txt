PROFILE PHOTO INSTRUCTIONS
==========================
Place your professional headshot photo inside this `images/` folder and name it:

  profile.jpg

Recommended specs:
- Dimensions: 500 x 500 px (1:1 square)
- Format: JPG (or update `images/profile.jpg` in index.html if using PNG/WebP)
- File size: 50 KB – 150 KB
